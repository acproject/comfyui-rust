# H3 Studio 中文使用说明书

> 桌面级 AI 影视制作工作站（egui + Rust 实现）。本文档面向中文用户，涵盖安装、语言切换、全部功能屏幕的使用方法及常见问题。

---

## 一、H3 Studio 是什么

H3 Studio 是一个基于 **egui** 的桌面端 **AI 影视制作工作台**，它把 ComfyUI 的生图/生视频能力包装成"项目 → 场景 → 镜头 → 素材 → 审查 → 导出"的一条完整生产流水线，并提供三套 GPU 管线：

- **FL2VA**：首帧/末帧 + 提示词，生成视频（MiniMax-H3 `i2va` 模式）
- **Ref2VA**：多模态参考（4 视角角色参考），生成视频（MiniMax-H3 `ref2va` 模式）
- **图像流程**：去背景 → 4 视图换正 → 参考图电影画质，可单独运行或串联成组合流程

应用启动后会连接本地 comfy-server（默认 `http://127.0.0.1:8188`），所有生成请求均通过该 HTTP 接口提交到 ComfyUI 服务器执行。

## 二、安装与构建

### 2.1 前置条件

- Rust 工具链（稳定版，`cargo`）
- Linux（推荐）；项目同时支持 Windows
- 一个在 `127.0.0.1:8188` 运行的 comfy-server（或传入自定义 URL，见 2.4）
- GPU 主机上需可用的 `nvidia-smi`（GPU 面板为实时监控，不可用时优雅降级，不会伪造数据）

### 2.2 构建

```bash
# 在仓库根目录
cargo build -p h3-studio          # 调试构建
cargo build -p h3-studio --release
```

生成的可执行文件在 `target/debug/h3-studio`（或 `target/release/h3-studio`）。

### 2.3 运行

```bash
./target/debug/h3-studio
```

### 2.4 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--screen <名称>` | 启动时打开的屏幕（如 `home`、`projects`、`storyboard`、`characters`、`assets`、`studio`、`queue`、`gpu`、`review`、`export`、`removebg`、`cinematic`、`multiview`、`combined`） | `home` |
| `--url <地址>` | comfy-server 的 HTTP 地址 | `http://127.0.0.1:8188` |
| `--lang <语言>` | 本次运行的初始界面语言（`zh` 或 `en`，不持久化） | 按本地配置 |
| `H3_SCREENSHOT_TO <路径>` | 环境变量：帧数后自动截取并退出（用于无头截图验证） | 未设置 |
| `H3_SCREENSHOT_FRAMES <N>` | 截图前等待的帧数 | `12` |

## 三、界面概览

窗口由三部分组成：

- **左侧边栏**：品牌区（H3 Logo + 产品名）、语言切换按钮、导航菜单、底部 GPU 状态胶囊
- **顶部栏**：当前屏幕的标题与副标题，右侧为当前屏幕的主操作按钮
- **底部状态栏**：连接状态指示灯（绿=已连接，红=离线）、服务器地址、右侧为已检测到的 GPU 数量
- **中央区域**：各功能屏幕的内容

### 3.1 全局中/英文切换

**位置**：左侧边栏，品牌区下方、导航菜单上方——一个两格分段按钮（`中文` | `EN`）。

- 点击 **中文**：全局界面切换为中文
- 点击 **EN**：全局界面切换为英文
- 切换后**即时生效且会保存**到本地状态文件 `~/.h3-studio/state.json`，重启后仍保持
- 运行时用 `--lang zh`（或 `en`）可在本次启动时临时指定语言，**不会覆盖**已保存的偏好

> 中文字体依赖系统字体（Droid Sans Fallback 等 CJK 字体）。若启动后中文显示为方块，说明系统缺少 CJK 字体，请安装 Noto Sans CJK 或 Droid Sans Fallback。

## 四、功能屏幕使用说明

### 4.1 首页（Home）

工作台首页，包含三块内容：

1. **最近项目**（左）：已保存项目的卡片列表（项目名、描述、上次修改时间、场景数/镜头数/生成数、生成进度条、角色模式标签）。点击卡片进入对应项目
2. **新建项目**（右）：填写项目名、选择宽高比（16:9 / 2.39:1 / 1:1 / 9:16）与风格预设（电影武侠 / 纪录片 / 工作室肖像 / 动漫手绘 / 黑色电影），点击**创建项目**。创建后自动跳到项目页并在右上角弹出 Toast 提示
3. **生成活动**（底）：展示正在运行的任务、GPU 实时利用率与显存/内存使用

**删除项目**：每张项目卡片的右上角有一个垃圾桶图标按钮（默认淡色，悬停或确认中高亮为红色）。点击后卡片底部会出现确认条「删除项目「项目名」？」，再点 **删除** 才会真正移除该项目（点 **取消**，或打开其它项目，都会放弃本次删除）。删除会从本地状态中移除该项目及其场景/镜头并写入 `state.json`；若删除的正是当前选中的项目，会自动清空选中状态，避免指向已不存在的项目。

顶栏右侧按钮 **新建项目** 点击后弹出 Toast（演示）。

### 4.2 项目（Project）

当前项目的工作台：

- **全局视觉设置**：项目级默认值 —— 宽高比、默认帧率、分辨率（项目与单个镜头都可覆盖）
- **场景**（右上）：分镜顺序列表，点击进入分镜编辑页
- **制作进度**（右下）：已完成镜头数与整体生成进度
- **角色库条带**：底部横条，展示角色（姓名、角色描述、一致性、引用数），点击跳转素材页

### 4.3 分镜（Storyboard）

- 顶部**镜头时间线**：显示场景 01 的镜头（号码 + 时长），点击选中
- 下方 **4×2 镜头卡片**：每个镜头由状态标签（已完成/运行中/排队中/待处理/失败）、缩略图和**生成**按钮组成
- 点击卡片选中该镜头，`生成` 按钮将镜头加入生成队列（演示）

### 4.4 角色库（Characters）

展示可复用角色（Xiao Mei / Uncle Chen / Captain Zhao / Bamboo Spirit 等），每张卡片包含：

- 头像、身份标记、项目/镜头引用数、Face-Hair-Form 三项一致性条
- 底部一致性进度条（按 `teal/indigo/amber/purple` 分色）
- 点击卡片跳转到参考素材页

### 4.5 参考素材（Assets）

- **导入区**（左上）：拖拽或点击选择图片文件，上传到素材服务器（仅作素材，不指定角色）
- **筛选**（左下）：类型（全部/图像/视频/音频）、角色（全部/角色/身份/服装）、项目（仅 Bamboo Grove）
- **素材库**（右）：服务器返回的素材网格；无素材时显示 6 张模拟占位卡（环境/角色/运动参考/姿态/音频/服装）

### 4.6 生成工作室（Generation Studio）

视频生成主屏幕，支持 FL2VA / Ref2VA 两种模式：

- **模式切换**（顶部分段控件）：`FL2VA · 首帧/末帧` 或 `Ref2VA · 多模态参考`；顶栏右侧也可用同一快捷键 **⌘↵** 切换
- **镜头上下文**（左）：当前镜头（S01 Shot 003）、角色参考、参考素材列表、能力状态（已支持/实验性/不支持）
- **视频预览**（中）：首帧+末帧预览，显示分辨率/帧率/时长
- **提示词面板**（右）：输入提示词，显示时长/帧率/模式与预计耗时，点击 **生成视频** 提交流水线图到服务器。提交后 Toast 提示已入队，完成后显示输出文件名用于预览

### 4.7 GPU 监控（GPU）

- 三张 GPU 卡片：显存已用/总量、利用率、温度、功率、当前任务
- 主机栏：RAM 用量/总量/百分比、CPU 百分比/活跃核心数
- 工作进程健康：每张 GPU 对应的工作进程状态（正常/警告）
- 顶栏 **自动刷新 1 秒**（演示）

### 4.8 生成队列（Queue）

实时显示服务器返回的队列：

- 顶部筛选胶囊：全部/运行中/排队中/已完成，并显示剩余时间估算
- 表格列：ID、镜头、模式、状态、进度、已耗时、GPU、操作（日志）
- 底部**任务日志**：最近一次任务的日志片段（模型加载、GPU 服务、编码、步数、VAE 解码等）

服务器离线时显示 3 行演示数据。

### 4.9 视频审查（Review）

- **版本**（左上）：v1/v2/v3 版本切换（FL2VA Master / Ref2VA 候选）
- **对比模式**（左下）：并排对比 / 叠加（点击芯片切换）
- **A/B 对比**（中）：A·v2 与 B·v3 候选播放器，点击播放并 Toast 提示；同步时间线支持拖动播放头（不漂移）
- **审查清单**（右上）：角色身份/面部几何/运动连续性/镜头运动/音频同步——点击行切换 PASS↔WARN，底部显示已通过数
- **评论**（右下）：最新评论摘要
- **镜头摘要**（底部）：最佳候选 + **将 A v2 提升为母版** / **用新种子重新排队 B** / **发送到导出** 三个按钮

### 4.10 导出（Export）

- **镜头选择**（左）：5 个镜头勾选（全选/全不选），时间线组装条
- **输出设置**（中）：容器（MP4/MOV/MKV）、分辨率（1080p/1440p/4K）、帧率（24/25/30/60），高级设置（编码/码率/颜色/音频混音）默认折叠，可点击展开
- **输出摘要**（右）：输出文件、时长、分辨率、编码、目标大小；进度条与 ffmpeg 命令；暂停/取消按钮

### 4.11 去背景（Remove Background）

- 节点链：LoadImage → RemoveBackground（bria-rmbg）→ SaveImage
- 参数：模型、输出格式（PNG·RGBA）、分辨率（1024×1024）、Alpha 抠图
- 点击 **生成** 后输出 `front_cutout.png`；底部可一键**保存到项目素材**
- 输出面板显示尺寸/文件/流程/馈入下一步（4 视图）

### 4.12 参考图电影画质（Cinematic from Reference）

- 节点链：LoadImage（参考卡）→ QwenImagePipeline（Qwen-Image-2.1）→ SaveImage
- 参数：模型、CFG、步数、分辨率（1344×768）、种子
- 点击 **生成** 输出 `cinematic_bamboo.png`，可保存到项目素材

### 4.13 4 视图换正（Multi-View Turnaround）

- 节点链：LoadImage（透明抠图）→ MultiViewPose → ImageGrid → SaveImage
- 视图：前/侧/背/顶视（正交四视图）
- 参数：主体锁定（相同的脸/发型/服装）、CFG 2.5、步数 40、网格 2×2、分辨率 1226×832
- 保存方式：**合并 2×2**（一个网格图）或**逐视图**（4 张独立 PNG）
- 点击 **生成** 后输出网格图；底部可**同时保存合并与逐视图**

### 4.14 组合流程（Combined Pipeline）

一站式总览面板，包含：

- **主链**（顶）：SOURCE → RemoveBackground → MultiViewPose → Save
- **并行分支**（下）：QwenImagePipeline（电影画质）→ Save
- 右侧**运行组合流程**按钮：一次性提交单个组合图（去背景 → 4 视图，电影画质并行）
- 下方**3 个步骤卡片**：去背景 / 参考图电影画质 / 4 视图换正——点击卡片跳转到对应屏幕独立运行

## 五、数据与持久化

| 位置 | 内容 |
|------|------|
| `~/.h3-studio/state.json` | 项目、角色、选中状态、**界面语言**（`language` 字段）。应用启动时读取；语言切换、项目创建等操作后写入 |
| 素材服务器 `/assets` | 通过导入区上传的素材文件 |
| 输入图片 `/input_images` | 工作流输入图片（LoadImage 等节点引用） |
| 输出图片 | 生成后的 PNG/视频（见输出面板中的文件名） |

> 项目/场景/镜头等是**应用内数据**，不会被翻译；只有界面文字在中英文切换时变化。

## 六、常见问题

**Q: 启动后右下角/状态栏显示"服务器离线"？**
检查 comfy-server 是否在 `127.0.0.1:8188` 运行（或用 `--url` 指定其他地址）。服务器离线时界面会显示演示数据，不会伪造 GPU/队列指标。

**Q: 状态栏显示 0 个 GPU？**
检查 `nvidia-smi` 是否可用（GPU 监控为实时采样，不可用时显示 0）。

**Q: 中文显示为方块（□）？**
系统缺少 CJK 字体。安装后重启应用；本应用会按 `Droid Sans Fallback → Noto Sans CJK SC` 的顺序回退（见 `fonts.rs`）。

**Q: 切换语言后没有生效？**
切换是即时生效的。若你修改了配置文件里的 `language`，确认值为 `zh` 或 `en`（大小写不敏感）。

## 七、注意事项

- 首页/导出/审查等屏幕中的部分控件（如镜头编辑器、队列暂停、快捷键、导出开始）为**演示用**，点击后 Toast 提示"即将推出"等，不持久化到真实服务
- 图像工作流（去背景/电影画质/4 视图/组合）已接入真实 HTTP 提交：生成后会轮询服务器，完成后显示输出文件并用于预览，支持下载到本地
- 项目/角色/镜头等数据均为演示种子数据，创建新项目后会追加到本地状态
